# Akiba Technologies  Software Engineering & Backend 

> **Batch 01 | Learn • Build • Connect • Grow**

This repository contains my learning journey, coding exercises, projects, technical notes, and backend engineering work throughout the **Akiba Technologies Software Engineering & Backend Bootcamp — Batch 01**.

The program focuses on developing strong software engineering fundamentals, problem-solving ability, backend development skills, and production-ready engineering practices.

---

## About the Program

The Akiba Technologies Software Engineering & Backend Bootcamp is a 6-month intensive program designed to develop software engineers through structured learning, technical mentorship, problem solving, collaborative engineering, and production-oriented projects.

The program follows four major phases:

1. **Python, OOP & Foundational Data Structures**
2. **Full DSA & Console Projects**
3. **Production Backend Development & APIs**
4. **Team Capstone & Production Deployment**

Each phase includes technical practice, projects, mentorship, and an evaluation before advancing to the next stage.

---

## My Learning Goals

Through this program, I aim to:

* Strengthen my Python programming fundamentals
* Develop strong problem-solving and algorithmic thinking skills
* Master important data structures and algorithms
* Build production-quality backend applications
* Design and develop RESTful APIs
* Work with relational databases and ORM tools
* Implement authentication and role-based authorization
* Write reliable and maintainable backend code
* Learn backend testing and system stability practices
* Understand Docker, CI/CD, and deployment workflows
* Improve Git and collaborative development practices
* Contribute effectively to team-based software projects
